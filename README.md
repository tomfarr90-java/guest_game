# Текстовый космический квест (Модуль 3)

Небольшой веб-квест, реализованный на базе классических Java-технологий (Сервлеты, JSP, JSTL) с использованием концепции **MVC (Model-View-Controller)**. Проект разработан в среде IntelliJ IDEA Community Edition и запускается на встроенном сервере Tomcat 9.

## 🚀 Функционал и особенности

* **Динамический сюжет**: Каждая сюжетная развилка зависит от предыдущего выбора пользователя.
* **Сохранение сессии**: В сессии (`HttpSession`) сохраняется имя игрока и счетчик сыгранных матчей.
* **Статистика в реальном времени**: На игровом экране отображается блок статистики, включая имя пользователя, счетчик игр и текущий IP-адрес (`IPv6` / `IPv4`).
* **Защита от F5 (Паттерн PRG)**: Применение паттерна *Post/Redirect/Get* предотвращает случайную повторную отправку форм и сброс прогресса при обновлении страницы.
* **Покрытие тестами**: Бизнес-логика переходов полностью изолирована от HTTP-запросов и покрыта модульными тестами JUnit 5.

## 🛠️ Стек технологий

* **Java 18** (Amazon Corretto)
* **Maven** (сборка проекта)
* **Java Servlet API 4.0.1 / JSP API 2.3.3**
* **JSTL 1.2** (Apache Standard Taglib)
* **Tomcat 9.x** (Embedded через Cargo Maven Plugin)
* **JUnit 5.8.2** (Модульное тестирование)

## ⚙️ Инструкция по запуску

Так как проект разработан в **IntelliJ IDEA Community Edition**, для запуска используется плагин **Cargo**, который автоматически разворачивает встроенный Tomcat 9.

### 1. Сборка проекта
Перед запуском сервера необходимо скомпилировать код и собрать `WAR` архив. В панели **Maven** (вкладка справа) раскройте `Lifecycle` и запустите:
* `clean`
* `package`

### 2. Запуск сервера Tomcat 9
В панели **Maven** раскройте папку `Plugins` -> `cargo` и дважды кликните по команде:
* `cargo:run`

После появления в консоли строки `Tomcat 9.x Embedded started on port [8080]`, откройте браузер и перейдите по адресу:
👉 **http://localhost:8080/guest_game/**

### 3. Запуск тестов
Чтобы запустить модульные тесты, откройте файл `GameServletTest.java`, нажмите правой кнопкой мыши в окне редактора и выберите **Run 'GameServletTest'** (или дважды кликните команду `test` в Maven Lifecycle).
